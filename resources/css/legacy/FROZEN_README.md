# Legacy CSS Files — Frozen

These files are kept for backward compatibility only.

- `landing-theme.css` — Legacy landing component classes
- `public-theme.css` — Legacy public theme overrides

**Do NOT add new styles here.** All new work should use:
- `design-tokens.css` for tokens
- `public.css` / `admin.css` / `client.css` for entry points
- `x-ui.*` Blade components for UI elements

These files will be removed after full migration (Phase 4 of the redesign plan).
